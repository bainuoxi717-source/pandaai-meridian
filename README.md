# PandaAI · 寂静子午线

以雨夜港口守护与进攻任务为框架的 3D 第一人称行为评估游戏。四种战术策略同时改变战斗能力和虚拟交易账户暴露；任务结束后生成六型交易人格身份证与可解释分析报表。

- 源码仓库：https://github.com/bainuoxi717-source/pandaai-meridian
- 建议使用电脑浏览器，开启硬件加速；移动设备也提供触控操作。

## 自动部署

推送到 `main` 分支后，GitHub Actions 会安装锁定版本的依赖，执行 TypeScript 检查与生产构建，再发布到 GitHub Pages。发布流程位于 `.github/workflows/deploy-pages.yml`。

构建时使用 GitHub Pages 返回的站点路径，确保脚本、样式、图标和字体在项目网址下正常加载。`dist/` 是生成文件，不提交到源码仓库。网站无需后台服务或 API 密钥。

发布方式参考 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 运行

需要 Node.js 22.16 或更新版本。

```sh
npm ci
npm run dev
```

## 构建

```sh
npm run build
npm run preview
```

`dist/` 为可静态部署的网站。游戏与评估完全在浏览器本地运行，不连接券商或真实账户。

## 任务目标

1. 约束或解决 4 名武装嫌疑人。
2. 保护并转移 2 名平民，尽量保持 AI 小队完整。
3. 回收调度室货单；可额外读取 3 处 Panda 行为线索终端。
4. 返回进入点，按 E 撤离并领取交易人格身份证与报表。

## 操作

- W A S D：移动；鼠标：观察；左键 / 右键：射击 / 机瞄。
- Shift / C：疾跑 / 蹲伏；E / R：交互 / 换弹。
- Space / G：劝降 / 闪光弹。
- 1 / 2 / 3：小队跟随 / 守候 / 清场。
- 4 / 5 / 6 / 7：稳态守护 / 证据扫描 / 协同演算 / 动能突破。
- 再次按 5：在冷却结束后发射扫描脉冲；再次按 7：启动 6 秒突破窗口。
- Tab / M：战术地图；Esc：暂停。

## 虚拟交易联动

初始虚拟资金为 100,000。市场每 4 秒推进一个 Tick，依次根据任务状态进入观察期、高波动、急跌冲击、证据修复和任务收盘。收益只作用于当前策略对应的虚拟暴露：

- 稳态守护：20% 暴露，减伤 35%，机动略降。
- 证据扫描：空仓观察，可揭示威胁和线索。
- 协同演算：45% 暴露，提高小队射速与机动。
- 动能突破：常态 35% 暴露；启动后 6 秒为 80% 暴露，提高机动与射速，同时增加受击风险。

系统记录净值、峰值、最大回撤、平均暴露、换手和调仓次数。人格主要由实际决策行为决定，不单纯奖励盈利或惩罚亏损。

## 人格评估

六型为守门·风控、猎手·趋势、工匠·因子、说书·宏观、跟影·风格、闯关·玩家。报告包含主型、副型、风险意识 / 证据验证 / 决策节奏 / 协同迭代四维雷达、六型得分、账户结果、行为证据、优势、盲区和训练建议。

证据覆盖度由战斗、守护、研究、策略切换和任务闭环五类样本计算，不代表心理测量信度。主副型分差小于 5 分时，报告会建议再测。该评估用于学习和自我观察，不是临床心理量表，不预测真实交易收益，不构成投资建议。

## 本地数据

设置、最高评分和最近五局记录仅保存在当前浏览器的 localStorage，不跨设备同步；清除浏览器数据会删除记录。身份卡可导出为 SVG 文件。

## 技术与许可

React、TypeScript、Vite、Three.js。场景和角色使用参数化生成，随机过程采用固定种子。字体与第三方依赖许可包含在项目中。
